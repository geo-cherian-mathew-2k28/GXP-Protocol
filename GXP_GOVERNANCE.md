# GXP governance proposal

Before a public release, establish:

- A named protocol maintainer group with transparent decision rights.
- Public issue tracking and a security disclosure contact.
- A version/compatibility policy and a documented change process.
- A requirement for two independent implementations to approve wire changes.
- A conformance-test contribution and release process.
- A published code of conduct, contribution agreement policy if desired, and
  owner-approved software licence.
- A clear distinction between project release, URI registration, trademark, and
  formal standards-body status.

Until those decisions are approved, this document is a proposal, not a claim of
community governance.
