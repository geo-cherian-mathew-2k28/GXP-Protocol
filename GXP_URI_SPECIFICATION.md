# GXP URI specification — provisional

The technical URI syntax and security boundaries are documented in
[specification/uri-specification.md](specification/uri-specification.md).

`gxp` is not registered or claimed. A GXP URI is a logical resource identifier,
not an HTTP endpoint, MQTT topic, browser handler, or authority-resolution
mechanism. The owner-only registration steps and prerequisites are in
[HUMAN_ACTION_REQUIRED.md](HUMAN_ACTION_REQUIRED.md).
