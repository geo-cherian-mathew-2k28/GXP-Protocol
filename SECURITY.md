# Security policy

## Status

GXP is experimental reference code and is not approved for production or
safety-critical use. See `docs/threat-model.md` and
`specification/security-specification.md`.

## Reporting a vulnerability

Until the project owner establishes a monitored security contact, do not open a
public issue containing an exploitable proof, credentials, device information,
or personal/location data. Contact the repository owner privately through the
security channel they publish, including affected revision, reproduction steps,
impact, and mitigation ideas. The owner must publish a response-time and
coordinated-disclosure policy before public release.

## Supported versions

There is no supported production release yet. The current `main` branch is
experimental and should be evaluated only in isolated development environments.
