# ADR-0008: GXP name and URI are provisional

- **Status:** accepted
- **Context:** A source repository cannot establish rights in `GXP` or
  registration of `gxp`.
- **Decision:** Documentation labels both as provisional. No submission,
  trademark claim, or public-release statement is made.
- **Consequences:** The owner must complete the checks and any submission; the
  project only supplies a technical draft and action checklist.
